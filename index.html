データと抽選について

人格名・囚人・星・シーズンは、lcbwikiの人格一覧を取得した固定スナップショット。 このページでは、画像・スキル説明・ゲーム内の排出率や入手可能性は扱わない。

抽選は現在の条件に含まれる人格を等確率で1件選ぶ。更新時は python3 scripts/update-data.py を実行してデータを再取得する。

GitHub Pagesなどで公開する場合は、出典元の転載方針と各権利者の条件を確認すること。
